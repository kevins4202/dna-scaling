# Project proposal

The repository root contains the compiled proposal PDF. This folder contains its editable LaTeX source.

Build from this folder with `make`. Requires a LaTeX installation providing pdflatex, geometry, mathptmx, microtype, amsmath, hyperref, and titlesec. Auxiliary files stay in build/; the final PDF is copied to the repository root.

The proposal has two pages of main text and a separate references page.
